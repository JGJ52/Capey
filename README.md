# Capey
![Time](https://hackatime-badge.hackclub.com/U0922GMGGTU/Capey)

## A modern cape mod where you can make and select your cape in-game

### Notes
- You can't toggle the elytra if you did not join any world since game launch.
- If you want to create capes, or you want others to see the cape you selected, you need to connect to the capey.app Minecraft server with a premium Minecraft account.
- With a cracked account, you can only see your selected capes locally, and you can't create capes.
- You can create 5 capes on a premium Minecraft account.
- You can't delete capes (yet).
- On the cape texture, you gotta figure out where and how to draw the elytra textures, because trust me, I don't know either.
